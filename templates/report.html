Celestyal Security Event Report - Last Week

Summary for the report

This report presents a detailed analysis of security events captured over the last week, extracted from Celestyal’s monitoring system via Wazuh. It includes a comprehensive chart of all types of actions, categorized by threat level to highlight the severity distribution of security events. Additionally, a frequency-based chart showcases the overall threat levels encountered during the period. The report also summarizes the key security events detected, providing insights into potential risks and attack attempts, aiding in real-time security posture assessment and incident response. Accompanying the visual data, a CSV file contains relevant event fields for further analysis.
